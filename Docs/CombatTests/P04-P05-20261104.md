시드는 11042026이며 정상/콤보/피격/대시 입력 위치에 0~45ms 변화를 적용했다. 매 50사이클 GC 후 월드 Actor 34개·소유 Component 71개가 유지됐다. 비용 실행에서 5개 공격 시작 중 정상 완료한 3개로 사이클 CPU 합을 나눈 정규화 수치는 고정 4.50ms, 시드 4.14ms다. 중단·대시 처리까지 포함한 값이다. 정확성 계측 시 메모리는 각각 56.39MiB·48.86MiB 증가했고, 상세 계측을 끈 비용 실행에서는 종료 시 각각 3.19MiB·4.28MiB 감소했다. 비용 실행의 마지막 100회 CPU가 처음보다 높았다. 제품 허용 예산이 미정이어서 자원·CPU는 MEASURED로 둔다.

제어된 에디터 Standalone Game에서 실제 전투 함수와 애니메이션 Notify를 사용했다. 몽타주·플레이어 HP 등을 격리한 구성으로 애니메이션 진행을 가속했고 렌더링은 NullRHI였다. 장시간 실사용 FPS·실시간 방치·사망/리스폰은 이 결과에 포함하지 않는다. 초기 두 워밍업 실패 후 검증용 두 번째 콤보 섹션의 종료 경계를 명시했다. 복원본의 영구 Draw 켜짐 예비 실행에서는 비용 계측도 약 250MiB 증가했다. 최종 네 실행은 제품과 동일한 Draw 꺼짐·제품 기본 콤보 참조 조건에서 Cook/빌드와 겹치지 않게 순차 실행했다.
