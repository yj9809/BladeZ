**배포 전 작업**

1. 실제 제품의 Cook 설정에 동적 로드 경로 `/Game/BZ/GameData`를 포함한다. 최초 패키지는 `DT_CharacterStat` 누락으로 게임 시작 중 크래시가 발생했다. 격리본에서 해당 경로 추가 후 재실행했다.
2. `BP_Crowd.uasset`와 `BP_Crowd_544.uasset` 원본을 복원하고 해시를 확인한다. 검증 당시 LFS 요청이 각각 404였으며, 대표 맵 패키지는 포인터 파일 두 개를 제외해 만들었다.
3. 격리본에서 정리한 중복 `MyClass` 리디렉트와 픽업 질량 설정 시점(CDO 생성자 → BeginPlay)을 제품 설정·코드에 반영할지 검토한다. 실제 배포 구성으로 다시 Cook하고 게임 시작, 주요 스테이지, 전투와 HitStop 복구를 확인한다. Shipping은 컴파일 성공까지 확인했다.

**재현 근거** · 측정 로그와 수정 전 실패 이력은 보존했다. 제품 작업공간에서 테스트 장치·상시 Draw를 제거하고 기본 콤보를 복구했다. 격리 재측정에는 정리 전 백업을 사용했다.
